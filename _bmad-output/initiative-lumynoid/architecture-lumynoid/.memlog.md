- (event) Fast path dipilih user; deliverable hanya spine (build-substrate), tanpa rendering tambahan
- (constraint) Dari tiket/keputusan (inherited, tidak dibuka ulang): Kotlin+Compose Android-only (K8,C12); harness native buatan sendiri (K4,C4); proot hanya saat tool shell (C6); event-driven tanpa always-on: exact alarm+notif+FGS selama tugas (C5); kartu dibuat app bukan LLM (K9,C9); BYOK OpenAI-compatible+Anthropic (K7,C10); tanpa Accessibility/kontrol app lain (C3); W^X targetSdk29+ (C7); tanpa server Lumynoid (C1); distribusi GitHub Releases+F-Droid (C14)
- (decision) AD-1 Paradigma hexagonal (ports & adapters): modul :core murni Kotlin/JVM tanpa android.*; adapter (llm, userland, web, skills, scheduler, data) dan :app bergantung ke :core, tidak pernah sebaliknya; adapter tidak saling bergantung. Mencegah: loop agent tercampur Compose/Service sehingga epic 3 dan 4 harus mengubah loop epic 2. Alasan: tujuh epic menempel di satu loop; port memberi titik sambung yang stabil.
- (decision) AD-2 Satu jalur eksekusi: setiap giliran LLM (chat polos epic 1, tugas agent, tugas terjadwal) masuk lewat TaskRunner.submit(TaskRequest) di :core, di-host AgentService (FGS specialUse) yang start saat tugas mulai dan stop saat antrean kosong. UI dan scheduler tidak memanggil LlmPort langsung. Mencegah: epic 1 membangun jalur chat terpisah yang lalu harus dibongkar epic 2; scheduler (epic 3) memanggil LLM sendiri. Trade-off: notifikasi FGS singkat juga muncul untuk chat polos — diterima demi satu jalur.
- (decision) AD-3 Antrean tugas serial: TaskRunner menjalankan maks satu tugas sekaligus (FIFO); tugas terjadwal yang tiba saat tugas lain jalan menunggu. Mencegah: dua userland/proses node paralel melanggar phantom process killer (32 child) dan batas memori Android 17; konflik tulis workspace.
- (decision) AD-4 Event log tunggal: eksekusi tugas menghasilkan TaskEvent bertipe yang di-append ke Room HANYA oleh TaskRunner (single writer). Transkrip percakapan, kartu aktivitas, kartu konfirmasi, log aksi R9, notifikasi hasil, dan status kuota semuanya proyeksi baca dari tabel ini. Delta streaming tidak dipersist (hot StateFlow); event persisten = batas tahan-crash. Mencegah: epic 3 menulis hasil ke percakapan dengan bentuk beda; log aksi menyimpang dari kartu.
- (decision) AD-5 Kepemilikan entitas: Conversation/Task/TaskEvent milik :core runner; ProviderConfig/ModelProfile/Secret milik :llm (epic 1), state rotasi/kuota milik router (epic 4); ScheduledTask milik :scheduler (epic 3); InstalledSkill milik :skills (epic 6); rootfs/workspace milik :userland (epic 2). Modul lain hanya membaca lewat port pemilik.
- (decision) AD-6 Kontrak tool: interface Tool di :core {name (regex ^[a-z][a-z0-9_]{0,63}$, prefiks per adapter: shell_, web_, skill_, schedule_), description, inputSchema (JSON Schema), assess(args)->RiskAssessment, execute(args, ctx)->ToolOutcome}. ToolRegistry satu-satunya cara mengekspos tool ke LLM; adapter mendaftar via ToolProvider. Nama tanpa titik karena regex nama tool OpenAI.
- (decision) AD-7 Gerbang konfirmasi di runner, bukan di tool: sebelum execute, runner memanggil tool.assess(args) (kode deterministik, tidak pernah klaim LLM). Kelas DESTRUCTIVE/FINANCIAL/EGRESS -> ApprovalRequested, tugas suspend sampai ApprovalResolved dari kartu app. Tidak dapat dinilai -> perlakukan sebagai butuh konfirmasi (default-deny). Persetujuan per panggilan di v1; tidak ada auto-approve dari LLM. Tugas terjadwal yang butuh konfirmasi: pause + notifikasi deep-link ke kartu; kedaluwarsa -> TaskFailed.
- (decision) AD-8 Konten tak tepercaya: output tool/web/skill masuk konteks hanya sebagai pesan role tool dengan penanda asal; runner hanya bertindak atas tool_calls terstruktur dari LLM, tidak pernah mem-parse teks output untuk instruksi kontrol. Dengan AD-7, injeksi paling jauh memicu tool call yang tetap melewati gerbang.
- (decision) AD-9 Egress lewat URL: web_read ke host yang tidak muncul di pesan user atau hasil web_search pada tugas yang sama dinilai EGRESS (butuh konfirmasi). Mencegah eksfiltrasi data lewat query string URL hasil injeksi. Markdown asisten tidak memuat resource remote otomatis (gambar remote tidak di-fetch, HTML mentah tidak dirender).
- (decision) AD-10 Kartu: ActivityCard/ApprovalCard/PreviewCard adalah komponen Compose yang dirender dari TaskEvent bertipe; teks LLM hanya tampil di bubble markdown. Renderer markdown tidak bisa menghasilkan komponen kartu. Isi kartu dari args tool call ditampilkan sebagai data berlabel (bukan teks bebas).
- (decision) AD-11 Port LLM: LlmPort.stream(LlmRequest): Flow<LlmChunk> dengan model pesan internal sendiri (system/user/assistant/tool, ToolCall{id,name,argsJson}); dua adapter wire: OpenAI Chat Completions-compatible dan Anthropic Messages, langsung Ktor+kotlinx.serialization, tanpa SDK vendor. Error dinormalisasi ke LlmError sealed {RateLimited(retryAfter), QuotaExhausted, AuthFailed, ToolsUnsupported, MalformedToolCall, Network, Server}.
- (decision) Library agent: tidak memakai Koog 1.0 maupun LangChain4j untuk loop dan klien LLM. Alasan: C4 harness sendiri; hanya 2 protokol wire (Rule of Three); epic 4 butuh akses header rate-limit mentah dan pemulihan tool call rusak di level wire; gerbang konfirmasi harus di loop kita. Koog dicek: 1.0 stabil Mei 2026, dukung Android — boleh ditinjau ulang bila protokol ke-3 muncul.
- (decision) AD-12 Router: rotasi key/provider, filter model supportsTools, dan pembacaan kuota diimplementasikan sebagai LlmRouter yang mengimplementasikan LlmPort (decorator) di :llm; runner hanya melihat LlmPort. Epic 1 mengirim router pass-through satu provider; epic 4 mengisi kebijakannya tanpa menyentuh runner. Pergantian provider dicatat sebagai TaskEvent ProviderSwitched.
- (decision) AD-13 Penyusunan konteks: ContextAssembler di :core (milik epic 4) membangun setiap LlmRequest dari event log; titik sambung ContextContributor dengan kelas Pinned (instruksi skill, system prompt — tidak pernah dipangkas) dan Trimmable (output tool, riwayat — dengan TruncationPolicy). Pemangkasan hanya untuk konteks; event log selalu menyimpan output penuh (R9). Epic 2 mengirim assembler naif.
- (decision) AD-14 Userland: satu API Userland.exec(cmd, cwd, env, timeout) di :userland; proot + loader dikirim sebagai .so di jniLibs (nativeLibraryDir, lolos W^X); rootfs diunduh saat pertama dipakai ke filesDir, dikunci checksum yang tertanam di build. Userland start lazy pada tool shell pertama dalam tugas dan dihentikan (semua proses anak di-kill) saat tugas selesai/gagal. Workspace per percakapan /workspace/<conversationId>; skill di /opt/skills bersama.
- (decision) AD-15 Secret: API key dienkripsi AES-GCM dengan kunci Android Keystore non-exportable, disimpan terpisah dari Room; tidak pernah masuk event log, log, konteks LLM, env userland, maupun Android auto-backup. Hanya adapter :llm yang mendekripsi. Tanpa Tink (cukup Keystore langsung).
- (decision) AD-16 Scheduler: ScheduledTask {schedule: Once|Daily|Weekly sealed, waktu lokal + zoneId, conversationId khusus per tugas terjadwal}; dibuat lewat SchedulerPort.create() baik dari layar maupun tool schedule_create. Alarm exact (SCHEDULE_EXACT_ALARM + onboarding) -> receiver -> start AgentService -> TaskRunner.submit(origin=SCHEDULED). Scheduler tidak memanggil LLM. Penjadwalan ulang alarm berikutnya dihitung saat fire dan saat BOOT_COMPLETED/TIME_SET.
- (decision) AD-17 Kebijakan dependensi F-Droid: tanpa Google Play Services/Firebase/FCM/ML Kit/analytics/crash reporter proprietary; hanya dependensi berlisensi OSI dari Maven Central/Google Maven; build reproducible dari tag.
